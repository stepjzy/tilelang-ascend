## 1. 协议

- **多实例交错扫描方法论沿用（Stage 2 §3 声明）**：同码不同 jit 实例存在双峰地址偏置（同变体两实例可差 +4%），单实例配对分辨率地板 ±0.8-4%——**每臂多实例交错构建（base1,del1,base2,del2,…）× 2 sweep（第 2 sweep 逆序消漂移）为终裁口径**；profiler 相对差禁用于变体排名（本 flow 已证伪）。
- 计时：graph-replay 纯 kernel（batch=25 / iters=10 / warmup=5，官方 G6 协议逐字）；官方 arange 构造 seed=42 逐字（offsets=[0,1023,2048]）。
- 规模：BI128 主报 5 实例/臂 × 2 sweep；BI32 控制臂 3 实例/臂 × 2 sweep。
- 精度门先行：交付 vs 基线 torch.equal（g_l 修复对官方口径行为不变的直接验证）。

### 3.2 机制判读（与 Stage 2 信号链一致，全部复现）

1. **V overlap 0.983→1.112**：移除相邻 mte3→mte2 排空对后，bulk 写（MTE3 busy +20%）与行读（MTE2）真实并发——SIDE_PAIR 串行化消除的直接引擎签名；
2. **C 读率 60.5→67.9GB/s（+12%）**：V 发射流平滑 → L2 仲裁间隙利用提升（联合分析 §1.3 机制，本轮数值更高因会话基态不同）；
3. **V F1 wait -17.7%**：V 提前完成引擎工作 → 对 C 节拍的等待前移但总量下降；
4. **确定性锚**（MTE1/Cube/Vector 逐位相同）证明两 profile 的计算路径零漂移，差异全部落在 DMA/同步层——与 P2 改动范围（仅移除一个保护对）精确对应；
5. **每核 spread 10.5→4.1µs** 与 Stage 2 实例级 29.6→7.8µs 同构——P2 的平滑化在核级与实例级同时收窄方差。

**口径声明**：msprof 相对差（-8.5%）与 graph-replay 配对差（-0.32%~-1.56%）不一致为已知伪影（profiler 对突发型基线的扰动大于平滑型 P2），**效应量级裁决以 §2 多实例配对为准**；本表引擎级指标作机制证据（方向性 + 确定性锚）。

## 6. 不确定性声明

1. 本轮 -0.32% 在多实例分辨率地板内（SE ≈ ±1.8%）：P2 效应量级的采信依据是**跨会话方向一致性（3/3）+ Stage 2 方差收窄 + 机制链**，非本轮单点；
2. msprof 相对差（-8.5%）系统性大于配对差（已知 profiler-变体不对称伪影），禁用于排名（重申）；引擎级采信依据含确定性锚（MTE1/Cube/Vector 逐位不变）；
3. 绝对值跨会话带 348.8–381.5µs（±5% 热态，ablation 纪律沿用）：本轮基态偏热（base 364.3 vs Stage 2 的 355.7）；
4. 联合带宽地板 ~333µs 为观测包络推导（995MB / 2.96TB/s），非硬件常数——开放角度未穷尽（联合分析 §3.3），不预判硬件下界；
5. 220µs 差距结论限定于"当前架构 + 已验证/已封死优化空间"；算法层流量消除与数据形态特化（panel，用户已排除）不在本结论范围内。
