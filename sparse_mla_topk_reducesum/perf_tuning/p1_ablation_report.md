## 3. 归因二分实验（C 侧协议 vs 结构 vs R2'）

| 变体 | 构成 | BI128 结果 | 结论 |
|---|---|---|---|
| base | 移除后基线（单槽 + 旧全排空门控） | 375.7µs | — |
| **p1_gate** | 双槽 L1 + Q 装载块内化 + 动态奇偶 region 索引 + **旧门控 gemm（不传 kwarg，无奇偶 if）** | **375.0µs（≈base）** | **P1 全部结构组件零成本；R2'（MTE1 时序→乒乓回归）排除** |
| p1（现行实现） | 双槽 + per-parity acquire/release + 奇偶拆分双静态模板调用 + 解除旧 MTE2 门控 | 398.2µs | 回归由**释放协议**（解门控）引起 |
| p1_lite（降级阶梯①） | 单槽 + 单事件 + opt-in 释放（1 块距离） | 397.7µs | 与 p1 同量回退——非双槽/非奇偶特有问题，是解门控本身 |
| C 侧隔离微基准（无 V/F0） | gate vs optin，102.4 块/核、165.9KB/块、DRAM 供流 | 411.4 → 403.0µs（**−2.0%**） | 协议在隔离下按设计工作（小幅正收益）；**负收益仅出现在与 V 耦合的真实算子中** |
| p1_hoistq | acquire+Q 前移至 F0 等待之前（恢复 Q 预取重叠假设） | 410.3µs（劣于 p1） | Q 位置假设证伪——非回归源 |

**归因结论**：解除 MTE2 自门控后，C 侧 MTE2 在 F0 就绪窗口内以引擎全速突发读
ws_kv，与 V 侧行读（MTE2）+ bulk 写（MTE3）争抢共享 L2/DRAM 服务——旧门控的
"每 gemm 周期一块"节奏实质上把 C 读与 V 流量做了时间交错；解门控破坏该交错，
双侧带宽效率同降（端到端 +4~6%）。这与 §6.3 节拍模型假设的"C 侧 MTE2 可在
52.7GB/s 上独立推进（加性带宽）"矛盾——52.7GB/s 是旧门控节奏下的**条件有效
带宽**，非可独占的引擎下限。R9 的反信号（msprof V 引擎和 375.8µs ≈ 墙钟
375.5µs，generic_pipeline_analysis §1.5）与本实验互证：**arange 口径为 V 近饱和
+ C/V 带宽耦合 regime**。

## 4.5 §9.4 sentinel-3（kvdb1 回退路径性能守门）

- **判定：PASS（二进制同一性）**——KVDB=1 触发配置（H=64/D=512/tail=512/topk=128/
  BI=64/S=512）下，P1 builder 与移除后基线生成的内核源码**逐字节一致**（14282B，
  /tmp/opencode/p1/diff_kvdb1_src.py）+ TIR structural_equal——同一二进制，性能
  不劣于现状由构造保证。
- 运行时配对复核：base 172.3µs vs P1(KVDB=1) 179.8µs（+4.3%）——**同码双实例
  对照实验**（同一基线 kernel 建两个 jit 实例配对测量）显示实例/地址级伪影
  +0.8%（round-0 达 +2.6% 后收敛），量级与方向匹配；结合二进制同一性，该差值
  归因为测量伪影而非代码属性。输出 torch.equal=True。

## 5. 预期带判定与证伪逻辑触发情况（§9.5）

- 端到端 **> 345µs（且相对基线配对净回退）** ⇒ **C 门控模型证伪——V 近饱和共
  门控嫌疑成立（R9 确认）** ⇒ 触发 **AIV/AIC 联合瓶颈分析**（Stage 3）：
  - msprof 复测 AIV 侧（V 引擎和/墙钟 ≈1.0 即 MTE3+vec 交替零重叠 → P2b
    方向（LEAD=3 前移 gather 发射点）+ P2（SIDE_PAIR=False）组合候选）；
  - 两侧引擎占空比数据先行，逐项归因后再立项（禁止盲目叠加，§9.5/§10.1）；
  - C 侧 MTE2 突发与 V 带宽耦合为新发现机制（本报告 §3），Stage 3 归因时须
    一并纳入（msprof L2 带宽/队列深度档位如可用）。
- P1 正确性交付完好：双臂全绿 + 位级稳定 + KVDB=1 臂 TIR 等价基线——若联合
  分析判定 C 侧优化暂不可收，§10.4.1 降级开关（KVDB 置 1，一行）可即刻恢复
  旧语义内核而保留框架 opt-in（S-P1a/c 证明对既有用户零影响）。
